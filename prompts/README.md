# prompts/

Prompts de los servicios de IA, versionados como archivos independientes.

Cada prompt debe poder identificarse por nombre y versión, de forma que cualquier
párrafo generado pueda decir con qué versión exacta se produjo (requisito de
trazabilidad del proyecto).

**Estado actual: vacía.** Los 9 prompts que la aplicación usa hoy están escritos
en línea dentro de `components/Peritia.jsx`, sin nombre ni versión. Su inventario
completo, con ubicación y propósito, está en `docs/AI_INVENTORY.md`.
