# knowledge/examples/

Casos reales o representativos, anonimizados, usados como ejemplos de
referencia: de qué aspecto tiene una extracción correcta, de qué aspecto
tiene una valoración típica, de qué aspecto tiene una redacción de conclusión
bien construida.

Su función principal es doble: servir de material de formación para peritos
nuevos, y servir de ejemplos de referencia (*few-shot*) para los servicios de
IA, en lugar de que esos ejemplos vivan incrustados en los prompts como
ocurre hoy (ver `docs/AI_INVENTORY.md`).

**Advertencia de privacidad:** todo ejemplo cargado aquí debe estar
anonimizado antes de incorporarse — el propio principio de seguridad del
proyecto ("todo documento contiene información personal sensible") se aplica
con el mismo rigor a este material.

Vacía.
