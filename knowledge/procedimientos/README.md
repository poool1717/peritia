# knowledge/procedimientos/

Procedimientos periciales: cómo se verifica un riesgo, cómo se documenta una
causa, qué comprobaciones son obligatorias antes de proponer indemnización.

Vacía. Hoy el procedimiento está implícito en el orden de las secciones del
editor (Encargo → Verificación → Causas → Valoración → Cobertura → Anexos).
