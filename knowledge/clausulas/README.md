# knowledge/clausulas/

Cláusulas tipo de póliza: coberturas, exclusiones, límites, franquicias y
condiciones especiales, con su redacción literal por compañía y producto.

Vacía. Hoy el texto literal de las cláusulas se extrae en cada informe desde el
PDF de la póliza mediante IA y se guarda dentro del JSONB del expediente; no
existe ningún catálogo reutilizable entre expedientes.
