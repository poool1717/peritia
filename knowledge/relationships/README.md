# knowledge/relationships/

Instancias concretas de relación entre unidades de conocimiento (por
ejemplo: "la garantía DAGUA protege el objeto tipo tubería", "el daño
'humedad por filtración' puede repararse mediante los métodos X, Y, Z"),
como datos, no como modelo.

Distinto de `knowledge/ontology/ONTOLOGY.md`, que define **qué tipos** de
relación existen y entre qué tipos de concepto (el metamodelo). Esta carpeta
contendría las relaciones concretas ya pobladas, conforme a ese metamodelo —
es, en la práctica, la materialización tabular de las aristas del
`knowledge/graph/KNOWLEDGE_GRAPH.md` antes de que exista, si se llega a
construir, un grafo de conocimiento real.

Vacía.
