# knowledge/branches/

Conocimiento específico de cada **ramo asegurador** (Hogar, Comunidades,
Empresa/Comercio, Industria, Automóvil…), como nodo de nivel superior de la
taxonomía (ver `knowledge/taxonomy/TAXONOMY.md`, sección "Ramos").

**Relación con `knowledge/hogar/`, `knowledge/empresa/` y
`knowledge/automovil/`** (Sprint 0): esas carpetas ya representan ramos
concretos como directorios de primer nivel dentro de `knowledge/`. Esta
carpeta introduce, en cambio, `branches/` como categoría contenedora
explícita de la taxonomía, coherente con el resto de categorías de este
sprint (`coverages/`, `causes/`, `materials/`…). No se han movido ni
fusionado los directorios existentes — ver reconciliación en
`KNOWLEDGE_ARCHITECTURE.md`.

Vacía. El diseño de qué ramos cubre el producto depende de
`docs/OPEN_QUESTIONS.md`, P-11.
