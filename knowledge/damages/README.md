# knowledge/damages/

Catálogo de tipos de daño (`Damage`, ver `docs/domain/entities/DAMAGE.md`):
clasificación estructurada de las consecuencias materiales que un siniestro
puede producir, con su relación a causas, objetos asegurados y métodos de
reparación aplicables.

Sin equivalente directo en Sprint 0 — el daño existía allí implícito dentro
de la descripción libre de cada partida del baremo, nunca como catálogo
propio y clasificado.

Vacía.
