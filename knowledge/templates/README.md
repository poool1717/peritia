# knowledge/templates/

Plantillas reutilizables: de redacción de secciones del informe, de
comunicación con el cliente, de solicitud de documentación pendiente. Se
diferencian de `knowledge/examples/` en que una plantilla tiene huecos por
rellenar (variables), mientras que un ejemplo es un caso completo y cerrado.

Es también el destino natural, en su forma madura, de las tres
implementaciones hoy paralelas de la plantilla de informe (vista previa,
Word, PDF — ver `docs/TECHNICAL_DEBT.md`, DT-07): si se llegan a unificar en
una única fuente (`docs/REFACTOR_BACKLOG.md`, R-13), esa fuente encajaría
conceptualmente aquí.

Vacía.
