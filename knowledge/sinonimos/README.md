# knowledge/sinonimos/

Diccionarios de sinónimos y variantes de escritura para normalizar lo que llega
de documentos reales (nombres de compañía, garantías, partidas, unidades).

Vacía. Hoy hay dos normalizaciones incrustadas en el código: `normCompania()`
—que fuerza cualquier variante de "AXA" a "AXA Seguros"— y `matchBaremo()`,
que empareja el texto devuelto por la IA con las partidas del baremo.
