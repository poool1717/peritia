# knowledge/documents/

Catálogo de tipos de documento relevantes para una peritación (encargo,
póliza, factura, presupuesto, informe catastral, DNI del perito…), con la
documentación exigible por cada tipo de siniestro o garantía (ver
`knowledge/ontology/ONTOLOGY.md`, relación *Garantía → requiere →
Documentación*).

Distinto de `docs/domain/entities/DOCUMENT.md` (Sprint 1), que modela el
documento como instancia dentro de un expediente concreto. Esta carpeta
modela, en cambio, el **catálogo de tipos** de documento y qué se exige de
cada uno con independencia de ningún expediente.

Vacía.
