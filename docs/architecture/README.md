# docs/architecture/

Documentos de arquitectura: visión de capas, límites de módulos, flujos de
datos, decisiones estructurales y diagramas de contexto.

Vacía a la espera de que la arquitectura oficial se defina fuera del código.
El estado **real** de la implementación actual está en `docs/CURRENT_IMPLEMENTATION.md`
y `docs/MODULES.md`, que describen lo que hay hoy, no lo que debería haber.
