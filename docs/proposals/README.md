# docs/proposals/ — Propuestas de arquitectura

Cuando la implementación detecta que la arquitectura oficial parece incorrecta o
insuficiente, **no se modifica la arquitectura**: se escribe aquí una propuesta y
se espera aprobación.

Nomenclatura: `YYYY-MM-DD-titulo.md`.

Cada propuesta debe incluir: Problema · Comportamiento actual · Alternativa ·
Ventajas · Inconvenientes · Impacto · Migración · Recomendación.
