# docs/domain/

Documentación del dominio de peritación de seguros: entidades, ciclo de vida del
expediente, vocabulario del negocio y reglas de negocio.

El dominio es la autoridad. El software se adapta al negocio, nunca al revés.
Ninguna regla de negocio debe inventarse aquí: este material lo define el
Arquitecto de Producto/Negocio.
