# docs/adr/ — Architecture Decision Records

Un ADR documenta una decisión de arquitectura: el contexto, las alternativas
consideradas, la decisión tomada y sus consecuencias. Una vez aceptado, un ADR no
se edita: si la decisión cambia, se escribe uno nuevo que sustituye al anterior.

Nomenclatura: `NNNN-titulo-en-minusculas.md` (por ejemplo `0001-persistencia-en-supabase.md`).

**Estado actual: no existe ningún ADR.** Todas las decisiones estructurales
tomadas hasta la sesión 22 están únicamente narradas en `CONTEXT.md`.
